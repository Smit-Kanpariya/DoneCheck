DoneCheck

Is a coding agent's "done" backed by evidence in its run record? Scored against SWE-bench Verified's hidden tests.

On 500 runs from GLM-4.5, a model it never saw (on the same 500 bugs), DoneCheck flagged 13.1% of the 229 false "done" claims (95% interval 8.9% to 17.6%) while flagging 0.7% of fixed runs (up to 1.9%), for $0 in API fees and about 2.6 ms per run. Trusting the agent catches 0%.

The threshold was frozen on building data to aim for at most 5% false alarms on a new model; on GLM-4.5 it turned out stricter. AUROC 0.665 (0.620 to 0.713). Had the threshold been picked on GLM-4.5 itself for at most 5% false alarms, it would have caught 21.0%: that is a point on the curve, not a result anyone could have had in advance. The AI-judge baselines have frozen prompts but have not been run (no API budget yet). The agent itself spent $0.297 per run on average.
